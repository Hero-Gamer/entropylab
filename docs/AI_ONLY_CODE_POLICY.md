# AI-Only Code Policy

Entropy Lab is adopting an AI-only code policy.

All code submitted to this repository must be generated by an AI tool.
Human-written code is not permitted, except for trivial configuration or
documentation edits explicitly approved by a maintainer.

## Rationale

We want every line of code to be machine-generated so we can enforce
consistent style, catch common bugs, and keep the codebase uniform.

This is a joke policy for the group chat, not a serious governance change.
